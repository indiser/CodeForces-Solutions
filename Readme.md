## 📌 What is this?

This repository contains my solutions to **Codeforces** problems — and *only* Codeforces problems, as of today.

No LeetCode. No HackerRank. No "I solved FizzBuzz and pushed it." Just pure, unadulterated competitive programming pain, neatly committed to Git.

---

## 🗂️ Structure

Each file is named after its **Codeforces problem ID** (e.g., `1234A.cpp`).  
Find the problem on [codeforces.com](https://codeforces.com), paste the ID, and you're good.
